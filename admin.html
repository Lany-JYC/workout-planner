🚀 发布到网站

你是直接双击打开的。推荐用 start.bat 启动以支持一键发布。

步骤 1：下载数据文件

点击按钮下载 exercises.js，保存到 data/ 文件夹替换原文件

步骤 2：推送到 GitHub

在项目文件夹打开终端，运行以下命令：

cd workout-planner git add data/exercises.js git commit -m "更新训练计划" git push

✅ 步骤 3：告诉老婆

推送后等 1-2 分钟刷新
